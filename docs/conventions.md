# Conventions (summary)

The full rules live in the `kb-notes` skill's conventions template, `.claude/skills/kb-notes/references/conventions-template.md`. Each vault keeps a localised copy at the path given by `conventions` in `kb.config.json`; in this vault that is [`90 System/CONVENTIONS.md`](../90%20System/CONVENTIONS.md), and agents read that copy. This page is a one-screen summary.

## Note types

| Type (`types.*`) | Folder | What it holds |
|---|---|---|
| `article` | `20 Articles` | one question, answered at textbook depth |
| `series-map` | `10 Series` | guiding question, intro, generated article entries |
| `series-front` | `10 Series` | "About this collection", "Notation and conventions" |
| `term` | `30 Terms` | one concept: definition, `defined_in` article |
| `literature` | `40 Literature` | bibliographic data and reading notes; citekey = note name |
| `home` | root | the dashboard |

## Articles in brief

- Open with 2–4 sentences posing the question; no meta paragraph. Every H2 is split into H3 subsections; nothing sits directly under an H2.
- Content goes into callout cards whose title starts with a kind word: `> [!definition] Definition — Title`, likewise Proposition, Derivation, Explanation, Caution, Conclusion, Concept (`intuition`). Cards are connected by 1–2 sentence question-driven bridges.
- A block id `^def-<prefix>-<slug>` follows every card, figure, key equation and table, after one blank line. Keep ids when content survives.
- Key equations only are numbered, `\tag{1}` … `\tag{N}` in order; referenced as `Eq. (n)`.
- Figures: `> [!figure] **Fig. n** caption with one clause per panel` + `![[stem.png|720]]`; after it, every panel is explained individually as `Fig. n(a)`, `Fig. n(b)`, … (what it shows and why, never a repeat of the caption), and a bare "(a)" never appears in the body (checked by `figure_audit.py`). Every figure comes from a script in `90 System/figure-scripts/`.
- Citations: `[[CiteKey|Author Year]]`, no locators. Cross-note references: `[[Article#^id|“Article” Eq. (n)]]`. Key terms link their card on first use: `**[[Term]]**`.
- Emphasis: `**term**`, `==key result==`, `***critical condition***`; no inline HTML, no TABs.
- The article ends with a `> [!series]` block: previous, next, series map. Frontmatter counts (`figures`, `equations`, `words`, `sections`, `kinds`) are recomputed by `note_stats.py --write`.

## Series maps

Entries are generated by `90 System/outline-sync.py`: `## [[Article]]`, the summary, then the article's H2 titles joined by ` · `, sorted by `seq`. Never edit entries by hand; edit the intro paragraph and question freely.
